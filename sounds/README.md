# Sounds

Organizacion de audio del proyecto:

- `ambient/`: lluvia, viento, tormenta y ambientes continuos.
- `interactions/`: puertas, interruptores y objetos recogibles.
- `footsteps/`: pasos por cada tipo de superficie.
- `objects/`: sonidos propios de muebles, maquinas y decoracion.

Los ambientes deben exponerse como escenas reutilizables para poder cambiar su
archivo o generador sin modificar la escena principal.
