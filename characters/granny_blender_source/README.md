# Abuela recreada en Blender

- `GRANNY_Rig`: armature principal de 16 huesos.
- `GRANNY_BackCurve_CTRL`: lattice para aumentar o reducir la curva de la espalda desde Edit Mode.
- `GRANDMOTHER_FINAL`: coleccion final del personaje.
- Las colecciones `Source_*` son referencias ocultas y no forman parte del GLB exportado.

El recurso listo para Godot se exporta en `../granny_blender/grandmother_recreated.glb`.
