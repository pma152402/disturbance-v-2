# Source assets

Archivos originales de Blender, FBX, GLB y DAE conservados para futuras ediciones.
No forman parte del juego en ejecucion y Godot ignora esta carpeta mediante
`.gdignore` para evitar importaciones duplicadas y acelerar el escaneo del proyecto.

La estructura interior conserva la ruta original de cada archivo.

`legacy_resources` contiene recursos Godot sin referencias actuales. Se
archivan aqui en lugar de borrarlos para que cualquier pieza pueda recuperarse.
